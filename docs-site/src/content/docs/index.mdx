## Windows companion app

Install swsd-mcp on this PC, save your JSON Web Token, and choose the tools your AI apps can use. Open **SWSD for AI apps** again from **SWSD Setup** on the Start menu. Home shows the connection and updates. Tools lets you search the catalog and build a custom profile you can share.
