<CardGrid stagger>
  <Card title="Any MCP client" icon="puzzle">
    Standard Model Context Protocol: works wherever MCP works. [See the compatibility matrix →](/compatibility/)
  </Card>
  <Card title="Zero credentials at rest" icon="seti:lock">
    Each user's SWSD token is forwarded per-request, never persisted, never logged.
  </Card>
  <Card title="Profile-scoped tools" icon="setting">
    Pick `triage`, `agent`, `knowledge`, `operations`, or `full` to control which of the 66 tools across 15 categories each deployment exposes.
  </Card>
  <Card title="Operations workflow" icon="seti:config">
    The `operations` profile adds change/release management, ITAM, CMDB lookup, procurement context, risk lookup, work logs, and attachments without enabling every tool.
  </Card>
  <Card title="Write safety controls" icon="seti:lock">
    Set `SWSD_WRITE_MODE` to `dry-run` to preview write payloads or `disabled` to block write tools while keeping read-only context available.
  </Card>
  <Card title="MCP Apps UI" icon="laptop">
    Seven read tools ship rich UI bundles for capable hosts: incident detail, solution detail, incident list, comment thread, audit timeline, catalog-item form, custom-field explorer. Text-only clients are unaffected.
  </Card>
  <Card title="Service Catalog" icon="add-document">
    Browse, inspect, and submit catalog requests with `swsd_list_catalog_items`, `swsd_get_catalog_item`, and `swsd_create_service_request`.
  </Card>
  <Card title="Self-hostable" icon="rocket">
    Stdio for local agents, Streamable HTTP for hosted/Copilot Studio. Docker image and Azure Container Apps recipe included.
  </Card>
  <Card title="Listed on the MCP Registry" icon="seti:json">
    Find `swsd-mcp` in MCP host install pickers via [registry.modelcontextprotocol.io](https://registry.modelcontextprotocol.io/v0.1/servers?search=io.github.mikimatsub/swsd).
  </Card>
</CardGrid>
